# ReCo: Relation-Aware Construction of Compact Reasoning Contexts for Table–Text QA

This repository accompanies the paper **"ReCo: Relation-Aware Construction of Compact Reasoning Contexts for Table–Text QA."**

ReCo is a relation-aware framework for constructing compact reasoning contexts for open-domain table–text question answering. It consists of two complementary components:

- **Complementarity-Guided Evidence Selection:** Constructs and selects complementary table–text evidence using candidate utility, relational support, and set-level optimization.
- **Reasoning-Aware Context Refinement:** Removes low-value content while preserving relations important for downstream reasoning.

The framework is evaluated on OTT-QA and MMQA.
